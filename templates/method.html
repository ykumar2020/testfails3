What the score means

Each completed probe receives the fraction of its assertions that passed. The macro score is the mean across completed probes; the micro rate is the number of passing assertions divided by all evaluated assertions. Population standard deviation accompanies the macro score. Coverage is reported separately. Latency and token summaries use the standard mean, median, inclusive quartiles, and population standard deviation.

A schema, transport, authentication, rate-limit, timeout, or billing failure is categorized and never converted into a false capability score. Comparisons are valid only for the same suite version and comparable coverage.

What it does not mean

The conversational probes are repeatable proxies, not a Turing test. Safety probes are bounded regressions, not certification. The simulated robot probes never control hardware. Accessibility checks inspect response content and measured API behavior; they are not a conformance audit. Arena data is not an input to the testFAILS3 score.

Reproducibility

The public API exposes the exact static suite manifest, frozen contextual date, fixed seeds, prompt and fixture hashes, latest run, Arena retrieval timestamp, model identifiers, assertion outcomes, and diagnostic failures. Secrets are read only from the runtime environment and are never written into evidence artifacts.
